=========================================
PYTHON TELEGRAM ADMIN BOT INSTRUCTIONS
=========================================

এই পাইথন বটটি আপনার ফায়ারবেস ডাটাবেসের সাথে কানেক্টেড। 
এটি সম্পূর্ণ ফ্রিতে 24/7 রান করার জন্য PythonAnywhere সবচেয়ে ভালো।

কিভাবে PythonAnywhere এ ফ্রিতে হোস্টিং করবেন:
১. www.pythonanywhere.com এ গিয়ে একটি ফ্রি একাউন্ট খুলুন।
২. "Files" সেকশনে গিয়ে একটি নতুন ফোল্ডার তৈরি করুন (যেমন: AdminBot)।
৩. সেই ফোল্ডারে এই জিপের "bot.py" এবং "requirements.txt" ফাইল দুটি আপলোড করুন।
৪. "Consoles" সেকশনে গিয়ে একটি "Bash" কনসোল ওপেন করুন।
৫. নিচের কমান্ডটি লিখে এন্টার দিন:
   pip install -r AdminBot/requirements.txt
৬. ইনস্টল হয়ে গেলে "Web" সেকশন থেকে "Always-on tasks" এ গিয়ে আপনার bot.py ফাইলটি রান করে দিতে পারেন অথবা কনসোল থেকেই রান করতে পারেন:
   python AdminBot/bot.py

এখন আপনার টেলিগ্রাম বটে গিয়ে /start দিন, মেনু চলে আসবে!
